2. Supabase Edge Functions Secrets: NOTION_TOKEN, SB_URL, SB_SERVICE_ROLE_KEY, ADMIN_SECRET, SITE_BASE_URL, REPORT_PATH 및 19개 DATA_SOURCE_*_ID, NOTION_*_DB_ID 3개를 설정한다. DB/데이터소스 ID는 운영 Notion에서 확인한 값을 사용한다. 기존 문서의 18개 외 DATA_SOURCE_PAYMENT_ID가 필요하다.
3. GitHub Settings → Secrets and variables → Actions: SUPABASE_PROJECT_ID, SUPABASE_ACCESS_TOKEN, SUPABASE_DB_URL, SUPABASE_ANON_KEY, ADMIN_SECRET. SUPABASE_DB_URL은 대상 프로젝트 Connect 화면의 실제 Session pooler URI(비밀번호 포함·특수문자 URL 인코딩)를 입력한다. 기존 SUPABASE_DB_PASSWORD만 입력해서는 이 운영 워크플로가 동작하지 않는다.
4. Supabase Vault sync_queue_admin_key를 ADMIN_SECRET과 동일하게 설정한다.
5. Solapi/학교 기능의 Secrets는 공통 이식 체크리스트를 따른다. 값이 준비되지 않은 알림톡 기능은 사용하지 않는다.
