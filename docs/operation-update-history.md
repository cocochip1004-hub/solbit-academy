## v2.6 업데이트 후보 준비 — 미배포

- 소유자 요청에 따라 Notion 수식·버튼·자동화 화면 작업은 추후 Claude Code/Chrome 연결 작업으로 분리한다. 대상은 원본 템플릿이 아니라 솔빛학원 운영 워크스페이스다.
- 사전 속성: 수업 보강, 출석 메모, 학습기록 주제 추가 및 등록 안내 링크→학생 페이지 이름 변경 완료. 기존 수식과 업무 행 보존.
- 코드 기준: 원본 v2.6.5 스냅샷 602c52a6cfcc2a423cfebd02db7619c82c9b3d07. 최신 v2.7 코드는 이번 후보에 혼합하지 않는다.
- 운영 main 기준: c3ffa2f26c75af0a02326339880d434912fcc1bd. 운영 주소·공개 anon 설정·리포트 경로·Session pooler Secret 및 기존 17개 마이그레이션을 보존한다. 원본 학생 번호 seed는 다시 넣지 않는다.
- 병합 중 설정 공통화 4파일, .gitignore, 웹훅 매핑 문서 충돌을 검토했다. 화면 설정은 새 공통 hada_config.js로 연결하고 운영값을 이관한다. ignore는 운영 제외 규칙과 원본 규칙을 합친다. 매핑 문서는 v2.6 지침으로 갱신하되 과거 운영 설명은 아래 이력으로 보존한다.
- 이전 매핑 이력: 클래스 편집→옛 웹훅(과거 이력 참조) 신규 연결 제외, 시간표 설정은 sync-registration-enroll. 등록 등 수정일 기록은 Notion 자체 액션이 있으면 옛 웹훅(과거 이력 참조)를 중복 연결하지 않는 기준이었다. v2.6은 수정일 기록을 Notion 자체 액션으로 정리한다. 실제 운영 자동화 정리는 아직 하지 않았다.
- 옛 함수 4개는 저장소 소스 정리와 서버 삭제를 구분한다. 운영 자동화 확인 전 배포된 함수는 삭제하지 않는다. ADMIN_SECURITY_ENABLED 활성화·Secrets 변경·과거 데이터 보정·기록 단원 일괄 채우기·실제 출결/알림톡 시험은 하지 않는다.
- 상태: 로컬 후보 준비. 코드 푸시·운영 DB 마이그레이션·함수/Pages 배포는 아직 실행하지 않음. 실제 배포는 수업·키오스크 미사용 시간 확인 후 진행한다.

- 과거 웹훅 이름을 포함한 원문은 [운영 과거 이력](updates/solbit-operation-archive-v25.md)에 보존함. 회귀 검사 제외 규칙을 바꾸지 않고 현행 연결 지침과 과거 기록을 분리함.

- SQL cron 테스트의 예상 endpoint도 운영 URL로 이식했다. 원본 URL 고정 비교 때문에 첫 검사는 실패했고, 마이그레이션과 동일한 운영 주소로 정확히 비교하도록 수정했다. 인증·예약·순서·권한 검증은 그대로 유지한다.

- 최종 로컬 검증 통과: Deno 모의 테스트 252개, 함수 진입점 43개 타입 검사, 격리 PostgreSQL 보안 검사 118개, 수업 복사본 테이블·cron 테스트 2종, 회귀 가드, 디자인 규칙, git diff 공백 검사. 운영 업무 기능 검증을 대체하지 않음.
